# GDD v1.4 — Unlocked-Slot Reroll Rule

## Evidence

During the first v0.3 Keep Validation games, keeping Team sometimes returned the
same Season. The complete three-slot result changed, so the v1.3 rule was working
technically, but the unlocked Season slot appeared not to reroll. This weakened
the clarity and perceived value of Keeps.

Used scorecard categories also remained visually too similar to selectable
categories, particularly when a strong scored result retained gold emphasis.

## Rule change

Whenever the valid pool permits it, every unlocked roulette slot must change.

- Keep Team: change Season and Player.
- Keep Season: change Team and Player.
- Keep Player: change Season and Team.
- Keep two slots: change the remaining slot.
- Keep none: change Season, Team, and Player.

If no valid outcome changes every unlocked value together, use a different
complete result. If only one valid record exists, permit that record to repeat.
All eligible outcomes remaining after this filter retain hierarchical equal
weighting.

## Interface clarification

Used categories receive a filled slate background, inset status bar, and check
badge. Strong used results may retain gold emphasis, but animated glow remains
reserved for currently selectable opportunities.

## Playtest handling

Do not mix pre-change v0.3 games with post-change v0.4 games. Preserve partial
Batch 2 logs as diagnostic evidence and begin a new ten-game **Playtest Batch 3
— v0.4 Unlocked-Slot Validation**.
