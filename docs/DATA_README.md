# NBA Roulette — 2023–24 data pilot

This folder is generated by `scripts/build_2023_24_dataset.py`.

## Canonical unit

One row represents one **player × team × season**. A traded player may therefore
have multiple rows, each containing only his statistics for that team.

## Eligibility

A row enters the roulette pool when both conditions are true:

- at least 15 regular-season games for that team;
- at least 10.0 minutes per game for that team.

## Outputs

- `data/processed/nba_roulette_2023_24.csv`: human-readable master table.
- `data/game/players_2023_24.json`: equivalent game-ready JSON.
- `data/processed/nba_roulette_2023_24_summary.json`: validation summary.
- `data/raw/2023-24/`: untouched NBA Stats API responses by team.

## Sources and joins

- Per-team regular-season statistics: NBA Stats `LeagueDashPlayerStats`.
- End-of-season team roster and jersey number: NBA Stats `CommonTeamRoster`.
- All-NBA, All-Defensive, MVP, DPOY, and Rookie of the Year: NBA's official
  2023–24 award announcements, encoded as small auditable lookup tables.
- Champion: Boston Celtics.

Each player-team-season uses the player's **final jersey number for that team**.
If a player wears #15 and later #29 for the same team, only #29 is retained. If
the player is traded, each team stint retains its own final number.

The NBA historical roster endpoint contains the end-of-season roster. Jersey
numbers for eligible players who left a team before season-end are therefore
kept in the script as explicit `(team, player_id) -> jersey` overrides. Every
override is checked against the official NBA box score for that player's final
regular-season appearance with the relevant team by
`scripts/verify_historical_jerseys.py`.

## Rebuild

```bash
python scripts/build_2023_24_dataset.py
python scripts/verify_historical_jerseys.py
```
