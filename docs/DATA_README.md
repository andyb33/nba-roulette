# NBA Roulette — data pipeline

The season datasets are generated by `scripts/build_dataset.py`, with awards
and champion metadata kept in `scripts/season_config.py`.

## Canonical unit

One row represents one **player × team × season**. A traded player may therefore
have multiple rows, each containing only his statistics for that team.

## Eligibility

A row enters the roulette pool when both conditions are true:

- at least 15 regular-season games for that team;
- at least 10.0 minutes per game for that team.

## Outputs

For each season, the pipeline writes:

- `data/processed/nba_roulette_<season>.csv`: human-readable master table;
- `data/game/players_<season>.json`: equivalent game-ready JSON;
- `data/processed/nba_roulette_<season>_summary.json`: validation summary;
- `data/processed/jersey_verification_<season>.csv`: final-game jersey audit;
- `data/raw/<season>/`: untouched NBA API responses, excluded from Git.

## Sources and joins

- Per-team regular-season statistics: NBA Stats `LeagueDashPlayerStats`.
- End-of-season team roster and jersey number: NBA Stats `CommonTeamRoster`.
- All-NBA, All-Defensive, MVP, DPOY, and Rookie of the Year: official NBA
  award announcements, encoded as small auditable season lookup tables.
- Champion: the official NBA Finals winner for that season.

Each player-team-season uses the player's **final jersey number for that team**.
If a player wears #15 and later #29 for the same team, only #29 is retained. If
the player is traded, each team stint retains its own final number.

The NBA historical roster endpoint contains the end-of-season roster. For an
eligible player who left a team before season-end, the pipeline finds his last
regular-season game for that team and reads the jersey number from the official
NBA box score. The result and game ID are retained in the season's jersey audit.
This implements the final-number rule without hand-maintained overrides.

## Rebuild

```bash
python scripts/build_dataset.py --season 2023-24
python scripts/build_dataset.py --season 2024-25
```

Raw responses and existing jersey audit rows are reused on later runs, so a
rebuild can resume after a temporary API failure.

## Distribution analysis

After rebuilding both season datasets, generate the descriptive balance report:

```bash
python scripts/analyze_distributions.py
```

The command writes a Markdown report, JSON summary, CSV tables, and charts under
`docs/` and `analysis/`. It reports both record-weighted distributions and the
game's equal Season → Team → Player roulette weighting.
