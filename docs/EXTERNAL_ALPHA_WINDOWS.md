NBA Roulette v0.4 — External Alpha (Windows)
================================================

HOW TO PLAY

1. Extract the ZIP file before opening the game.
2. Double-click NBA-Roulette-v0.4-External-Alpha.exe.
3. Keep the small server window open while playing.
4. The game opens automatically in your default browser.
5. Close the server window when you are finished.

No installation, GitHub account, or Python setup is required. The game runs
only on your computer and does not expose a public web server.

PLAYTEST LOGS

Completed games are saved locally in:

Documents\NBA Roulette\playtest_logs

Please send the .csv and .jsonl files in that folder back to the developer
after your playtest. Starting an unfinished game does not add a log entry.

WINDOWS SECURITY NOTICE

This is an unsigned early prototype. Windows SmartScreen may display a warning
because the app does not yet have a paid code-signing certificate. If you trust
the person who sent you this build, choose "More info" and then "Run anyway".
